🛑 Agent 优雅中止 · 四道防线控制台第十章 Demo · SSE + CancellationToken + asyncio.cancel + Partial Yield

提交一个 Agent 任务 → 通过 SSE 实时看它跑 → 随时点红色 Stop。看它怎么被“优雅叫停”。

① 交互层异步提交先拿 task_id，SSE 长连接推送每一步，红色 Stop 按钮下发 CANCEL_TASK。
② 循环层Agent Loop 每次调 LLM/工具前插桩查取消状态，撞上 cancelled 就跳出（只拦“动作之间”）。
③ 底层force 取消会对正在跑的 asyncio.Task.cancel()，掐断卡在 20s 网络 I/O 里的协程。
④ 兜底层捕获中止信号 → 回滚临时表/删除临时文件 → 基于已收集事实输出 Partial Yield。
取消方式：
尚未提交任务。
